Health probes

Liveness /health …
Readiness /ready …

Failures clear themselves after the timer, so a pod that is not ready can come back on its own. First, add the probes:

oc set probe deployment/ --liveness --get-url=http://:8080/health --period-seconds=10 oc set probe deployment/ --readiness --get-url=http://:8080/ready --period-seconds=5

Then watch the pods: oc get pods -w (the liveness failure shows up in RESTARTS).

CPU stress (HPA)

Keeps one CPU core busy on this pod.

oc set resources deployment/ --requests=cpu=100m oc autoscale deployment/ --cpu-percent=50 --min=1 --max=5 oc get hpa -w
